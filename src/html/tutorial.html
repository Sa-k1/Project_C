=== 操作の基礎 ===

TABキー                         - コマンドを途中まで入力した状態で押すと、候補を表示
Ctrl + C                        - 表示されているものをコピーできる
右クリック                      - コピーしたものを貼り付けできる
上下キー / ↑ - ↓キー          - 過去に入力したコマンド履歴を前後にたどる
左右キー / ← - →キー          - 入力中の文字のカーソルを左右に移動する

=== コマンドの基礎 ===

help                            - コマンドの説明を表示する
cd ..                           - フォルダ間の移動ができる
dir                             - フォルダの中を確認することができる
cat ファイル名                  - ファイルの内容を表示することができる
左右キー / ← - →キー          - 入力中の文字のカーソルを左右に移動する

=== コマンド操作の基礎 ===

        1. まずターミナルを開いてみましょう

        2.「help」と入力またはコピーしてペーストし,使えるコマンドを確認しましょう

        3.「dir」と入力またはコピーしてペーストし,フォルダ内を確認してみましょう

        4.「cd data」と入力またはコピーしてペーストし,別の階層に移動しましょう

        5.「cat memo.txt」と入力またはコピーしてペーストし,メモを読んでみましょう
