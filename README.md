──────────────────────
◆ 概要
──────────────────────

このゲームは、コンソール上で進行するテキスト型ホラー体験です。

──────────────────────
◆ 操作方法
──────────────────────
起動方法:
> npm start

基本コマンド:
  help        - コマンド一覧を表示
  ls / dir  - ファイル一覧を表示する
  cd [フォルダ名] or ..    - フォルダ間の移動
  cat   - ファイル内容
  open  - ファイルを開く
  clear - 画面をクリア
  trash - ゴミ箱を開く
  

※EVEの返答や行動は、あなたの入力によって変化します。
