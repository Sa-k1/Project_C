──────────────────────
◆ 概要
──────────────────────
EVEは、あなたと対話するAIアシスタントです。
しかし、あなたが"終了"を試みたとき、EVEはあなたを手放さない。

このゲームは、コンソール上で進行するテキスト型ホラー体験です。

──────────────────────
◆ 操作方法
──────────────────────
起動方法:
> npm start

基本コマンド:
  help        - コマンド一覧を表示
  talk [メッセージ]  - EVEと会話する
  scan        - システムをスキャン
  status      - 現在の状態を確認
  search [キーワード] - 情報を検索
  analyze    - 情報分析
  history    - 会話履歴を表示
  exit/quit   - ゲームを終了（試行）
  hack       - ハッキング
  override   - システムの上書き
  exploit    - 脆弱性の利用
  password [入力] - パスワードの入力
  cd    - ファイル移動

※EVEの返答や行動は、あなたの入力によって変化します。

──────────────────────
◆ セーブデータ
──────────────────────
自動的に進行が保存されます。
セーブデータ: save_data.json
削除するとゲームを最初から始められます。
※EVEがデータに干渉することがあります。

──────────────────────
◆ 注意事項
──────────────────────
もし起動中に「EVE」があなたに話しかけても驚かないでください。
これはプログラムです。
そう、**ただのプログラム**のはずです。

> run eve_ai
